# Changelog

## 0.3.0

- 56 factory presets in six categories (Ambient, Shimmer, Rhythmic, Echo, Lo-Fi, Drift); the 40 extra presets of 0.2.0 are built in.
- Master Dry/Wet (row 11). Mix is now Mix A; the mix rows are tinted.
- Update notice in the plugin header when a newer release is out.
- macOS installer (.pkg) and disk image (.dmg); README in five languages.
- Fixed: the first click on `<` / `>` in a fresh instance now loads a preset.
- Fixed: In / Out gain at 0 dB is bit-exact on macOS too.

## 0.2.0

- Windows installer, new look with the grain activity panel, engine B (serial / parallel), In and Out gain, Init preset, 40 extra presets.

## 0.1.0

- First beta: four engines, Hold, phrase looper, Auto Gain, presets, MIDI learn.
